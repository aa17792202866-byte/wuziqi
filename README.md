# 对弈 · 联机五子棋

基于 HTML、CSS、JavaScript、Node.js 和 SQLite 的局域网双人五子棋。

## 启动

1. 安装 Node.js 24 或更高版本。当前电脑已具备运行环境。
2. 双击 `start.bat`，或在项目目录运行 `npm start`。不需要 `npm install`。
3. 打开 http://localhost:3210 并注册账号。
4. 好友在同一局域网打开页面底部的地址，注册另一个账号后即可互相邀请。

请保持服务器电脑及启动窗口运行。端口默认 3210，可设置环境变量 `PORT`。数据库默认放在 `data/gomoku.sqlite`，首次启动自动创建。停止服务可在启动窗口按 Ctrl+C。

## 操作方式

- **账号**：账号不区分大小写，昵称允许重复。登录状态保持七天；同一账号换设备登录后可以查看原来的棋谱。点击顶部昵称可修改名字。
- **大厅**：实时显示在线棋友，空闲时可以直接邀请；也可以创建房间并通过六位房间码加入。邀请支持接受、拒绝、撤回和三十秒自动过期。
- **准备**：双方准备后开局。黑方可以直接「让对方先手」；白方需要「申请先手」并获得同意。交换后双方重新准备。
- **对战**：黑棋先行，无禁手，连续五颗或更多同色棋子获胜。双方确认后可悔一步或重新开始。
- **投降**：点击投降并自行确认，立即判负，对手不能拒绝。对手断线时仍可投降。主动离开进行中的棋局或退出登录也需确认并按投降处理。
- **断线**：刷新、关闭标签页或短暂断线不会立即判负；同账号重新进入可恢复座位。对手离线时暂停落子，十秒后从大厅在线列表移除。
- **历史**：在「我的对局」查看、筛选和分页浏览自己的对局。胜负、平局和双方重开均有相应记录。
- **复盘**：支持前后步、开局/终局、拖动进度、点击步序、自动播放及速度调整。左右方向键切换步数。投降局显示真实终止原因。
- **当前比赛与复盘**：查看历史不会离开现有房间，点击「当前对局」即可返回。

## 数据安全与恢复

密码使用带独立随机盐的 scrypt 哈希，登录使用 HttpOnly、SameSite Cookie。所有房间操作和历史访问由服务器校验。每一步确认后保存在 SQLite，服务重启可恢复棋盘；未开始的准备状态和申请会清除。

### 本地账号管理

在服务器电脑的项目目录打开 PowerShell，可交互式创建账号或重置密码：

```powershell
npm run user:create
npm run user:reset -- 账号
```

密码输入不会显示明文。重置密码会注销该账号已有的登录状态，但不会删除历史对局。

数据备份运行 `npm run backup`。数据结构、备份恢复和升级说明见 `DATABASE.md`。

## 验证

- `npm test`：规则、账号、权限、邀请、交换先手、投降、去重、数据库失败回滚、重启恢复等检查。
- `scripts/browser-qa.js`：供 Playwright CLI 执行的双浏览器交互验证，测试时使用端口 3211 的独立数据库。不要对真实用户数据库创建测试账号。
- `VALIDATION.md`：本次验证记录。
- `REQUIREMENTS.md`：用户提供的需求说明书原文。

## 已知边界

- 当前用于本地电脑和可信局域网，未配置公网部署、HTTPS或防火墙放行。公网访问需另行配置 HTTPS，并设置 `COOKIE_SECURE=1`。
- 页面可能列出多个网卡地址，应选择当前以太网或 Wi-Fi 的局域网地址。另一台设备不能使用 localhost；访客网络隔离及防火墙可能阻止访问。
- 没有邮箱找回密码、聊天、观战、人机或排行榜；请保管好账号密码。
- 不自动判定断线超时负。进行中的双方可以重连继续；已连接方可以投降结束。
- 使用单进程服务和本地 SQLite，未进行大规模并发压测。
- 旧版本的内存匿名棋局没有持久化数据可迁移；新账号和棋谱从本版开始保存。

## 人机模式（V1.1）

大厅新增「人机对战」，提供三档难度和执棋颜色设置。电脑计算使用独立线程，无需外部服务。支持单方确认的悔棋、重开和投降，棋局与历史继续保存到 SQLite。历史新增联机/人机筛选。

详细策略、恢复行为和已知限制见 `AI.md`。电脑并非注册账号。原联机功能保持可用。
