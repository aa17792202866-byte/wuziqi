# 对弈 · 联机五子棋

使用 HTML、CSS、JavaScript 和 Node.js，自带服务器，不需要安装第三方依赖。

## 在本地电脑运行

1. 双击 start.bat。电脑需已安装 Node.js 18 或更高版本（当前电脑已安装）。
2. 浏览器访问 http://localhost:3210，点击「创建房间」。
3. 另一台电脑或手机连接同一 Wi-Fi，访问页面下方列出的局域网地址，输入六位房间码加入。
4. 黑方先行。请保持服务器电脑及启动窗口运行，关闭窗口会停止服务。

命令行也可以运行 npm start，使用 npm test 检查规则与联机流程。端口默认 3210，可通过环境变量 PORT 更改。

## 功能

- 两台设备实时同步，房间最多两人，黑白双方轮流落子。
- 15×15 棋盘，无禁手，横、竖、斜连续五颗或更多同色棋子获胜。
- 悔一步和重新开始需对方同意；请求可拒绝或撤回。
- 显示落子顺序、上一手位置、获胜连线、对局计时。
- 手机适配、键盘方向键移动及回车落子。
- 同一标签页刷新可恢复座位；短暂断线后自动重连，断线期间禁止落子。

## 网络说明

这是本地运行、局域网访问的版本。另一台设备不能使用 localhost，需要使用服务器电脑的局域网地址。如果无法访问，请检查是否同一网络、是否为隔离的访客 Wi-Fi，以及 Windows 防火墙是否允许 Node.js 在专用网络中接收连接。可能列出多个网卡地址，应选当前 Wi-Fi 或以太网对应的地址。

异地联网需另行配置公网部署或安全的内网穿透，当前没有配置。当前项目的 Node.js 服务包含联机状态，不能只上传 dist 静态目录来实现联机。

房间和棋局保存在服务器内存；服务重启会清空。同一标签页的身份保存在 sessionStorage；返回大厅或关闭标签页后不能只凭房间码找回已占用座位。无人连接的房间闲置六小时后清理。
